Role

Unattended desktop control

The seats will use your screen with no prompt, including while you are away. This is not the working folder — it is the actual desktop this app is running on.
  • They can read any window's contents, click, type and press keys.
  • Nothing pauses to ask you, and a Keep Improving run can do this for hours.
  • The pointer never moves and windows are never brought to the front, so you may not notice it happening.
  • Alloy still refuses its own windows and password fields — those two hold at every setting and cannot be turned off.

Unattended browser control

The seats will click and type on the sites you listed, with no prompt. A real Chrome, on your machine, driven while you are away.
  • Anything a visitor to those sites could do, a seat can do — submit forms, post, buy, delete.
  • The site list is the boundary and it is a hard one: Chrome blocks every address not on it, including your own files. That still does not limit what happens inside a listed site.
  • A fresh, empty browser profile is used, so nothing you are signed into elsewhere carries over.

Keep Improving — before you start

This runs unattended and does not finish on its own. The seats will keep editing files in your working folder, and when they finish a job the manager invents the next one and starts again. Nobody reviews the work between rounds unless you set the check-in to ask you. Permissions in force: .

Event hooks

      
    

    
A shell command run when the event happens — e.g.
      ssh phone termux-notification -t Alloy --content "$AICHAT_DETAIL".
      The command receives AICHAT_EVENT, AICHAT_SESSION, AICHAT_TITLE and
      AICHAT_DETAIL (a short excerpt). Leave a box empty for no hook. Hooks are
      best-effort: failures and slow commands (10 s cap) stay silent.
